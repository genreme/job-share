**Tool handlers (10 total):**

1. `captureInterviewTranscript(args)` - INTV-09
   - args: { jobId, sessionType, interviewDate, interviewType, rawTranscript, interviewerName?, confidenceLevel?, overallVibe?, highlights?, duration?, practiceSessionId? }
   - Validates required fields
   - Calls captureTranscript service
   - Returns { success, transcriptId, message }

2. `getInterviewHistory(args)` - Primary organization per CONTEXT.md
   - args: { jobId?, limit?, chronological? }
   - If jobId provided: getTranscriptsForJob (grouped by job)
   - If chronological=true or no jobId: getTranscriptsChronological (timeline view)
   - Returns { interviews: [...], count }

3. `searchTranscripts(args)` - Full-text search
   - args: { query, jobId?, sessionType?, limit? }
   - Calls searchTranscriptsService
   - Returns { results: [...], count }

4. `proposeInterviewLearnings(args)` - Claude proposes learnings
   - args: { jobId, transcriptId, learnings: [{ content, topic, outcome, sourceQuote? }] }
   - For each learning, calls queueInterviewLearning
   - Returns { proposed: count, learnings: [{ id, hasSuggestedLinks }] }

5. `reviewInterviewLearning(args)` - User accepts/rejects
   - args: { learningId, decision: 'accept' | 'reject' }
   - Calls reviewLearningService with { status: decision === 'accept' ? 'accepted' : 'rejected' }
   - If accepted, calls updateProfileConfidence with learning.outcome
   - Returns { success, learning }

6. `linkLearningToProfile(args)` - Suggest profile links
   - args: { learningId }
   - Get learning, return suggestedProfileLinks
   - Returns { learningId, suggestedLinks: [...], hasLinks: boolean }

7. `confirmProfileLink(args)` - User confirms link
   - args: { learningId, entityType, entityId }
   - Calls linkLearningService
   - Returns { success, link }

8. `getProfileUpdateSuggestions(args)` - Batch/aggregate
   - args: { mode?: 'batch' | 'aggregate' }
   - Calls getUpdateSuggestionsService
   - Also calls detectConflicts
   - Returns { suggestions: [...], conflicts: [...], hasConflicts: boolean }

9. `getInterviewPatterns(args)` - Recurring patterns
   - args: { minOccurrences?, minCompanies? }
   - Calls getPatternsService
   - Returns { patterns: [...], count }

10. `getCaptureReminders(args)` - 24h reminder
    - args: { jobId? }
    - If jobId: check single job
    - If no jobId: check all active jobs
    - Returns { needsCapture: [...], count }
  </action>
