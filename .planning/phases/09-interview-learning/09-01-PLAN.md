<task type="auto">
  <name>Task 1: Create Interview Learning Schemas</name>
  <files>schemas/interview-learning.schema.js</files>
  <action>
Create new schema file with Zod schemas following existing learning.schema.js patterns:

**InterviewTranscriptSchema:**
- id: z.string().uuid()
- jobId: z.number()
- sessionType: z.enum(['practice', 'real-interview'])
- interviewDate: z.string() (ISO date)
- interviewerName: z.string().optional()
- interviewType: z.enum(['phone', 'video', 'onsite'])
- confidenceLevel: z.enum(['high', 'medium', 'low']).optional()
- overallVibe: z.enum(['went-well', 'neutral', 'rough']).optional()
- rawTranscript: z.string()
- highlights: z.array(z.string()).default([])
- capturedAt: z.string() (ISO date)
- duration: z.number().optional() (minutes)
- practiceSessionId: z.string().uuid().optional() (links to Phase 8 practice)
- interviewerResearchId: z.string().uuid().optional()

**InterviewLearningSchema:**
- id: z.string().uuid()
- jobId: z.number()
- transcriptId: z.string().uuid()
- extractedAt: z.string() (ISO date)
- content: z.string()
- sourceQuote: z.string().optional()
- topic: z.enum(['technical', 'behavioral', 'company-specific', 'compensation'])
- outcome: z.enum(['worked', 'needs-work', 'neutral'])
- suggestedProfileLinks: z.array(z.object({
    entityType: z.enum(['story', 'skill', 'summary']),
    entityId: z.string().uuid(),
    linkReason: z.string()
  })).default([])
- confirmedProfileLinks: z.array(z.object({
    entityType: z.enum(['story', 'skill', 'summary']),
    entityId: z.string().uuid(),
    linkedAt: z.string()
  })).default([])
- status: z.enum(['proposed', 'accepted', 'rejected'])
- reviewedAt: z.string().optional()

**TranscriptStorageSchema:** (for {jobId}-transcripts.json)
- interviews: z.array(InterviewTranscriptSchema)
- lastUpdated: z.string()

**LearningStorageSchema:** (for {jobId}-learnings.json)
- learnings: z.array(InterviewLearningSchema)
- lastUpdated: z.string()

Add validation functions following learning.schema.js pattern:
- validateInterviewTranscript(data, options)
- validateInterviewLearning(data, options)
- validateTranscriptStorage(data, options)
- validateLearningStorage(data, options)

All validators support { mode: 'advisory' } (default) and { mode: 'strict' }.

<task type="auto">
  <name>Task 2: Create Interview Capture Service</name>
  <files>mcp-server/src/services/interview-capture.js</files>
  <action>
Create transcript capture service following practice-session.js patterns:

**File structure:**
```javascript
import { v4 as uuidv4 } from 'uuid'
import { readFileSync, writeFileSync, existsSync, mkdirSync, renameSync, readdirSync } from 'fs'
import { join, dirname } from 'path'

import { differenceInHours, parseISO } from 'date-fns'
import { validateInterviewTranscript, validateTranscriptStorage } from '../../../schemas/interview-learning.schema.js'
```

**Functions to implement:**

1. `captureTranscript(transcript)` - Save interview transcript
   - Validate with InterviewTranscriptSchema
   - Generate UUID if not provided
   - Set capturedAt to now if not provided
   - Load existing transcripts for jobId
   - Append new transcript
   - Use atomic write pattern (temp file + rename)
   - Return { captured: true, id, transcriptCount }

2. `getTranscriptsForJob(jobId)` - Get all transcripts for a job
   - Load from job-research/{jobId}-transcripts.json
   - Return { interviews: [], lastUpdated } structure
   - Return empty array if file doesn't exist

3. `getTranscriptsChronological(options = { limit: 50 })` - Timeline view
   - Scan all *-transcripts.json files in job-research/
   - Flatten and sort by interviewDate descending
   - Add jobId to each result for context
   - Apply limit

4. `searchTranscripts(query, options = {})` - Full-text search
   - Options: { jobId, sessionType, limit: 20 }
   - Normalize query to lowercase
   - Split into words, require ALL words to match
   - Search rawTranscript content
   - Return matches with context snippet (50 chars before, 200 chars after first match)
   - Sort by date descending

5. `checkTranscriptReminder(jobId)` - 24h reminder logic
   - Load job data to find recent interviews (from updates array)
   - Check if any interview within last 7 days has no transcript captured
   - For each uncaptured interview > 24 hours old, flag for reminder
   - Return { needsReminder: boolean, interviews: [{ interviewDate, hoursSince, message }] }

**Constants:**
- DATA_DIR: mcp-server/data
- RESEARCH_DIR: mcp-server/data/job-research
- Use atomicWriteSync helper function (copy from practice-session.js)
