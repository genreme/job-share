     - 'inbox' bottleneck: "Consider reviewing inbox jobs more frequently"
     - 'apply-now' bottleneck: "Jobs flagged as apply-now may need follow-through"
     - 'applied' bottleneck: "Long wait after applying is normal; consider follow-up"

4. Use date-fns for all date calculations (already in project from Phase 2).

Note: If simple-statistics not available, implement basic percentile calculation:
```javascript
function percentile(arr, p) {
  const sorted = [...arr].sort((a, b) => a - b)
  const idx = (p / 100) * (sorted.length - 1)
  const lower = Math.floor(idx)
  const upper = Math.ceil(idx)
  if (lower === upper) return sorted[lower]
  return sorted[lower] + (idx - lower) * (sorted[upper] - sorted[lower])
}
```
