  <action>
Create analytics.js with MCP tool handlers for all analytics features:

**Funnel Tools (ANLT-01):**
1. `get_funnel_metrics` - Get Sankey diagram data
   - Params: `{ dateRange?: { start: string, end: string }, preset?: '7d'|'30d'|'90d'|'all' }`
   - Returns: `{ nodes, links, totalJobs, dateRange }`
   - Calls calculateFunnelMetrics from funnel-calculator.js

**Response Rate Tools (ANLT-02):**
2. `get_response_rates` - Get response rates by dimension
   - Params: `{ dimension: 'companySize'|'industry'|'applicationMethod'|'jobBoard'|'roleType' }`
   - Returns: `{ dimension, rates: [{ value, rate, sampleSize, confidence }], overall }`
   - Calls calculateRatesByDimension from response-rate-analyzer.js

3. `get_time_to_response` - Get response time distribution
   - Params: none
   - Returns: `{ averageDays, medianDays, percentiles, display }`
   - Calls calculateTimeToResponse from time-in-stage.js

**Time-in-Stage Tools (ANLT-05):**
4. `get_time_in_stage` - Get time metrics per status
   - Params: `{ status?: string }` (optional, returns all if omitted)
   - Returns: `{ stages: [{ status, averageDays, medianDays, percentiles, sampleSize }] }`
   - Calls calculateTimeInStage from time-in-stage.js

5. `get_bottlenecks` - Identify process bottlenecks
   - Params: `{ threshold?: number }` (default 7 days)
   - Returns: `{ bottlenecks: [{ status, averageDays, recommendation }] }`
   - Calls identifyBottlenecks from time-in-stage.js

**Skill Gap Tools (ANLT-03):**
6. `get_skill_gaps` - Get aggregated skill gaps
   - Params: `{ minOccurrences?: number }` (default 3)
   - Returns: `{ gaps: [{ skill, count, priority, industries, roles }], total }`
   - Calls aggregateSkillGaps from skill-gap-aggregator.js

7. `get_skill_gap_recommendations` - Get actionable gap recommendations
   - Params: none
   - Returns: `{ recommendations: [{ skill, priority, rationale, actionType }] }`
   - Calls getGapRecommendations from skill-gap-aggregator.js

**Criteria Evolution Tools (ANLT-04):**
8. `get_criteria_recommendations` - Get fit criteria evolution suggestions
   - Params: none
   - Returns: `{ recommendations: [{ type, criteria, suggestedValue, confidence, rationale }] }`
   - Calls generateRecommendations from criteria-recommender.js

9. `preview_criteria_change` - Preview impact of criteria change
   - Params: `{ change: { type, criteria, value } }`
   - Returns: `{ affected, scoreChanges: [...], summary }`
   - Calls previewCriteriaChange from criteria-recommender.js

10. `apply_criteria_change` - Apply recommended criteria change
    - Params: `{ change: { type, criteria, value }, reason: string }`
    - Returns: `{ success, config? }`
    - Calls applyCriteriaChange from criteria-recommender.js

**Snapshot Tools:**
11. `get_analytics_snapshot` - Get current or historical snapshot
    - Params: `{ date?: string }` (ISO date, omit for current)
    - Returns: snapshot object with all metrics

12. `save_analytics_snapshot` - Save current state as snapshot
    - Params: none
    - Returns: `{ success, snapshotDate }`

Follow existing tool handler patterns from mcp-server/src/tools/ directory.
