<task type="auto">
  <name>Task 1: Create interview.schema.js with all Phase 8 schemas</name>
  <files>schemas/interview.schema.js</files>
  <action>
Create Zod schemas following existing patterns from research.schema.js and learning.schema.js:

**InterviewerResearchSchema** (extends HiringManagerResearch pattern for per-person research):
- id: z.string().uuid()
- jobId: z.number()
- interviewerName: z.string()
- interviewerTitle: z.string().optional()
- interviewRound: z.string().optional() (e.g., "phone screen", "onsite", "final")
- researchedAt: z.string()
- background: object with currentRole, company, previousRoles[], yearsInRole, linkedInUrl
- interviewStyle: object with signals[], expectedQuestionTypes[] (enum: behavioral, technical, system-design, culture-fit, case-study), communicationPattern, depthExpectation (enum: surface, moderate, deep)
- talkingPoints: z.array(z.string()).default([])
- sharedInterests: z.array(z.string()).default([])
- confidence: z.enum(['high', 'medium', 'low'])
- sources: z.array(z.string()).default([])

**InterviewQuestionSchema** (per CONTEXT.md: linked to stories + talking points):
- id: z.string().uuid()
- jobId: z.number()
- questionText: z.string()
- category: z.enum(['behavioral', 'technical', 'system-design', 'culture-fit'])
- difficulty: z.enum(['easy', 'medium', 'hard'])
- source: z.enum(['jd-requirement', 'profile-gap', 'profile-strength', 'company-research', 'interviewer-style'])
- sourceDetail: z.string().optional()
- suggestedStories: z.array(z.object({ storyId: z.string().uuid(), storyTitle: z.string(), relevanceScore: z.number() })).default([])
- talkingPoints: z.array(z.string()).default([])
- generatedAt: z.string()
- interviewerId: z.string().uuid().optional()

**PracticeAnswerSchema** (per CONTEXT.md: comprehensive scoring):
- questionId: z.string().uuid()
- answerText: z.string()
- inputMethod: z.enum(['text', 'voice'])
- answeredAt: z.string()
- duration: z.number().optional() (seconds if voice)
- score: z.object({ overall, storyCoverage, starStructure, relevance, clarity - all 0-100 }).optional()
- feedback: z.object({ strengths[], improvements[], suggestedRewrite }).optional()

**PracticeSessionSchema** (per CONTEXT.md: all sessions saved per job):
- id: z.string().uuid()
- jobId: z.number()
- sessionType: z.enum(['full-interview', 'category-focus', 'single-question'])
- startedAt: z.string()
- completedAt: z.string().optional()
- answers: z.array(PracticeAnswerSchema).default([])
- feedbackTiming: z.enum(['immediate', 'batched'])
- summary: z.object({ questionsAttempted, averageScore, strongCategories[], improvementAreas[] }).optional()

**PrepProgressSchema** (per CONTEXT.md: overall trend dashboard):
- jobId: z.number()
- lastUpdated: z.string()
- totalSessions: z.number().default(0)
- totalQuestionsAnswered: z.number().default(0)
- scoreHistory: z.array(z.object({ date, category, score })).default([])
- readiness: z.object({ overall 0-100, byCategory record, confidenceLevel enum }).optional()
- focusAreas: z.array(z.object({ category, reason, recommendedPractice })).default([])

Include validation helper functions following learning.schema.js pattern (validateInterviewerResearch, validatePracticeSession, etc.) with advisory/strict modes.

<task type="auto">
  <name>Task 2: Create interviewer-research.js service</name>
  <files>mcp-server/src/services/interviewer-research.js</files>
  <action>
Create service following manager-research.js pattern exactly:

**startInterviewerResearch(jobId, interviewerName, interviewerTitle, interviewRound)**
- Return template structure with status: 'template_ready'
- Template includes all InterviewerResearchSchema fields with sensible defaults
- Instructions focus on:
  1. Interview Style Signals (PRIMARY): Glassdoor patterns, typical approach
  2. Communication Style: Direct, collaborative, detail-oriented
  3. LinkedIn Activity: Recent posts, engagement topics
  4. Shared Interests: Content, groups, interests overlap
  5. Talking Points: Specific rapport-building topics
  6. Background (SECONDARY): Role, trajectory, education

**saveInterviewerResearch(jobId, findings)**
- Validate using InterviewerResearchSchema.safeParse()
- Return validation errors if invalid
- Save to {jobId}-interviewer-{sanitizedName}.json using atomicWriteSync
- Generate and save {jobId}-interviewer-{sanitizedName}.md using generateInterviewerMarkdown()
- Return { success: true, saved: { json, markdown } }

**getInterviewerResearch(jobId, interviewerName)**
- Load from {jobId}-interviewer-{sanitizedName}.json if exists
- Return null if not found
- Validate loaded data before returning

**listInterviewerResearchForJob(jobId)**
- Glob for {jobId}-interviewer-*.json files
- Return array of { name, researchedAt, confidence } summaries
- Enables checking which interviewers already researched

**generateInterviewerMarkdown(research)** (internal)
- Format: Talking Points first (most important)
- Then: Interview Style signals
- Then: Shared Interests, LinkedIn Presence
- Last: Background (secondary)

Use sanitizeName helper to make filename-safe (lowercase, replace spaces with dashes, remove special chars).

Follow atomic write pattern from manager-research.js. Store in mcp-server/data/job-research/ directory.
  </action>
