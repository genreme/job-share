Create scoring service per CONTEXT.md requirements (comprehensive evaluation):

**scoreAnswer(answer, question, profile)**
Parameters:
- answer: { answerText, inputMethod }
- question: { questionText, category, suggestedStories, talkingPoints }
- profile: Full profile for reference

Returns score object:
```javascript
{
  overall: 75, // 0-100, weighted average
  storyCoverage: 80, // Did they use suggested stories?
  starStructure: 70, // S-T-A-R components present?
  relevance: 85, // Does answer address the question?
  clarity: 65  // Clear, concise communication?
}
```

Scoring heuristics:
- storyCoverage: Check if answer mentions story keywords/themes from suggestedStories
- starStructure: Look for situation setup, task description, actions taken, results achieved
- relevance: Compare answer keywords to question keywords
- clarity: Sentence length, filler word ratio, concrete vs abstract language
- overall: Weighted average (30% relevance, 25% structure, 25% coverage, 20% clarity)

**generateFeedback(score, answer, question)**
Returns feedback object per CONTEXT.md (numeric + qualitative):
```javascript
{
  strengths: ["Good use of specific metrics", "Clear situation setup"],
  improvements: ["Could strengthen the result section", "Add more action details"],
  suggestedRewrite: "..." // Concrete example if score < 70
}
```

Feedback generation:
- strengths: Identify what scored well (>75 in a dimension)
- improvements: Identify what scored poorly (<70 in a dimension)
- suggestedRewrite: Only if overall < 70, provide concrete improvement

**suggestRewrite(answer, question, profile)**
- Find best matching story from profile
- Extract relevant talking points
- Generate improved answer structure showing:
  - Better situation setup
  - Clearer task framing
  - More specific actions
  - Quantified results where possible

Per CONTEXT.md: "Specific rewrites showing how the answer could be improved with concrete examples" - NOT vague feedback like "be more specific"

**calculateReadiness(progress)**
Returns readiness object:
```javascript
{
  overall: 72, // 0-100
  byCategory: {
    behavioral: 80,
    technical: 65,
    'culture-fit': 70
  },
  confidenceLevel: 'needs-work' // 'not-ready' | 'needs-work' | 'ready' | 'well-prepared'
}
```

Calculation:
- overall: Average of recent scores (last 10 answers per category)
- byCategory: Average by category from scoreHistory
- confidenceLevel thresholds:
  - 0-50: 'not-ready'
  - 51-70: 'needs-work'
  - 71-85: 'ready'
  - 86-100: 'well-prepared'

Identify focusAreas:
- Categories with score < 70
- Categories with < 3 practice answers
- Include reason and recommendedPractice for each

**getPreInterviewChecklist(jobId)**

