<task type="auto">
  <name>Task 2: Add Friend Submission MCP Tools</name>
  <files>mcp-server/src/tools/discovery.js</files>
  <action>
Extend discovery.js with three new functions for friend submissions:

1. `getFriendSubmissions()`:
   - Check isSupabaseConfigured(), return helpful error if not
   - Query job_submissions table for status='pending', order by created_at desc
   - Map results to include friendContext object:
     ```javascript
     friendContext: {
       submittedBy: sub.submitted_by,
       connection: sub.connection_notes,    // How they know you
       benefits: sub.benefits_notes,        // Why it's good for you
       reasoning: sub.reasoning             // Personal recommendation
     }
     ```
   - Return { count, submissions, message }

2. `processFriendSubmission({ submissionId })`:
   - Fetch single submission by ID from Supabase
   - Call existing researchJobUrl() with submission.url
   - Combine research result with friendContext
   - Return combined result with nextStep guidance

3. `acceptFriendSubmission({ submissionId, status, notes })`:
   - Validate submissionId and status (apply-now, maybe, probably-not)
   - Get submission from Supabase
   - Check for duplicate using findDuplicateByUrl()
   - Create new job entry with:
     - source: 'friend-submission'
     - friendContext preserved in job object
     - notes include friend's reasoning
     - updates array has initial "Friend Submission" entry
   - Update Supabase status to 'accepted'
   - Write to jobs.json via writeJobsData()
   - Return success with job and friendContext

IMPORTANT: Preserve friend context throughout the flow (DISC-07b requirement).
The friendContext object must be stored in the job data, not just displayed once.
  </action>
