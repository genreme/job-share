  <action>
Create job verification service for staleness detection:

1. Create `job-verifier.js` with:

   **verifyJobStatus(url)**:
   - Check JOB_VALIDATOR_URL env var
   - Call Worker /status endpoint with POST { urls: [url] }
   - Return { status: 'active'|'closed'|'uncertain', reason }
   - Handle network errors gracefully

   **verifyActiveJobs()**:
   - Load jobs from dashboard via loadJobsFromDashboard()
   - Filter to active jobs (not archived, has URL)
   - If no Worker configured, return { error: 'Worker not configured' }
   - Batch check status via Worker /status endpoint
   - For each job:
     - Track active/closed/uncertain counts
     - If data changed (title/salary from Worker), recalculate fit score
     - Track updated jobs
   - Save updated jobs via writeJobsData() if any changes
   - Return summary:
     ```javascript
     {
       checked: number,
       active: number,
       closed: number,
       uncertain: number,
       updated: number,
       closedJobs: [{ id, title, company, reason }],
       updatedJobs: [{ id, title, newFitScore, oldFitScore }]
     }
     ```

   **Import from existing modules:**
   - loadJobsFromDashboard, writeJobsData from loader.js
   - calculateFitScore from fit-scorer.js

2. Error handling:
   - Network timeout after 30 seconds
   - Graceful fallback if Worker unavailable
   - Log warnings but don't fail on individual job errors
  </action>
