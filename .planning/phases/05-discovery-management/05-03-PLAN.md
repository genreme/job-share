2. Create `mcp-server/src/services/fit-config.js` with:

   **loadFitConfig()**:
   - Load from fit-config.json
   - Return DEFAULT_CONFIG if file missing
   - Handle parse errors gracefully

   **saveFitConfig(config)**:
   - Atomic write using temp+rename pattern
   - Update lastUpdated timestamp
   - Increment version

   **updateFitCriteria({ adjustment, reason })**:
   - Load current config
   - Apply adjustment (e.g., add industry to preferred)
   - Log to evolutionLog with timestamp and reason
   - Save updated config
   - Return { success, config }

   **logOutcome({ jobId, outcome, notes })**:
   - Load config
   - Add to evolutionLog: { timestamp, jobId, outcome, notes }
   - Outcomes: 'applied', 'interview', 'offer', 'rejected', 'withdrew'
   - Save config
   - Return { success }

3. Update `mcp-server/src/services/fit-scorer.js`:
   - Import loadFitConfig from fit-config.js
   - Modify calculateFitScore to:
     - Try loadFitConfig() first
     - Use config.criteria for title/industry/location/salary matching
     - Use config.weights for scoring
     - Fall back to DEFAULT_FIT_CRITERIA if config load fails
   - Keep calculateDefaultFitScore unchanged (internal fallback)

IMPORTANT: fit-scorer.js must remain backward compatible. If fit-config.json doesn't exist, use existing DEFAULT_FIT_CRITERIA.

2. Create `mcp-server/src/services/board-registry.js` with:

   **loadBoardRegistry()**:
   - Load from job-boards.json
   - Return INITIAL_BOARDS if file missing

   **saveBoardRegistry(registry)**:
   - Atomic write using temp+rename pattern

   **getBoardsForScan()**:
   - Filter to status='active' boards
   - Sort by tier (ascending), then qualityRating (descending)
   - Return sorted array (DISC-13: high-quality prioritized)

   **addBoardForTesting({ name, urlPattern })**:
   - Generate id from urlPattern (sanitized)
   - Create board with tier=3, qualityRating=0.5, status='testing'
   - Add to pendingReview array
   - Save and return new board

   **updateBoardMetrics({ boardId, found, valid, stale })**:
   - Find board by id
   - Increment metrics
   - Recalculate qualityRating = valid / (valid + stale)
   - Adjust tier based on rating (only after 10+ samples):
     - >= 0.8: tier 1
     - >= 0.6: tier 2
     - < 0.4: add to pendingReview (flag for human review)
   - Save and return updated board

   **blacklistBoard({ boardId, reason, userConfirmed })**:
   - REQUIRE userConfirmed === true (DISC-14: user confirmation)
   - Find board, set status='blacklisted'
   - Add to blacklist array with timestamp and reason
   - Save registry
   - Return { success, message }
