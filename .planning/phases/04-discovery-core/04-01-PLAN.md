Create StatusTransitionSchema:
```javascript
export const VALID_TRANSITIONS = {
  'inbox': ['apply-now', 'maybe', 'probably-not', 'archived'],
  'apply-now': ['applied', 'maybe', 'probably-not', 'archived'],
  'maybe': ['apply-now', 'probably-not', 'applied', 'archived'],
  'probably-not': ['maybe', 'archived'],
  'applied': ['archived'],
  'archived': [] // Terminal state
};

export function isValidTransition(from, to) {
  return VALID_TRANSITIONS[from]?.includes(to) ?? false;
}
```

<task type="auto">
  <name>Task 2: Create fit-scorer service with profile integration</name>
  <files>mcp-server/src/services/fit-scorer.js</files>
  <action>
Create fit-scorer.js service that calculates job fit scores using profile preferences.

Key implementation details:

1. **Profile-based scoring** (when profile.preferences.targetRoles is populated):
   - Role fit (max 25 points): Match job title against targetRoles[].titles.exact (25) or partial (15)
   - Industry fit (max 20 points): Match against targetRoles[].industries.preferred (20) or acceptable (10)
   - Location fit (max 15 points): Match against targetRoles[].locations.preferred (15) or acceptable (8)
   - Salary fit (max 15 points): Compare against targetRoles[].salary.minimum
   - Skills alignment (max 10 points): Match job description against profile.skills[].name (2 points per match, max 5 matches)
   - Base score: 50 points

2. **Fallback to defaults** (when targetRoles is empty):
   - Log warning: `console.warn('Profile targetRoles is empty - using default fit criteria')`
   - Use hardcoded FIT_CRITERIA matching worker/job-validator.js pattern
   - Return { score, breakdown, usingDefaults: true }

3. **Helper functions:**
   - `parseSalaryFromText(salaryText)` - Extract numeric salary from strings like "$120,000 - $150,000"
   - `matchesKeywords(text, keywords)` - Case-insensitive keyword matching

4. **Fresh profile loading:**
   - Call `loadProfile()` fresh each time (don't cache) to pick up profile updates
   - Handle profile load errors gracefully with fallback

Export: `calculateFitScore`, `calculateDefaultFitScore`, `parseSalaryFromText`
