  <name>Task 1: Create reasoning-generator service</name>
  <files>mcp-server/src/services/reasoning-generator.js, mcp-server/src/services/reasoning-generator.test.js</files>
  <action>
Create reasoning-generator.js that explains why a job was included in the shortlist.

Key functions:

1. **generateReasoning(job, fitResult)**
   - Takes job data and fit score result
   - Returns:
     ```javascript
     {
       score: number,
       summary: string,        // One-liner explaining the match
       whyIncluded: string[],  // Positive signals (reasons to apply)
       considerations: string[], // Concerns or notes
       breakdown: {            // Score breakdown explanation
         role: "X/25 points - [reason]",
         industry: "X/20 points - [reason]",
         location: "X/15 points - [reason]",
         salary: "X/15 points - [reason]",
         skills: "X/10 points - [reason]"
       }
     }
     ```

2. **Reasoning logic:**
   - role >= 20: "'{title}' matches your target roles"
   - role >= 10: "Title has partial alignment with your targets"
   - role < 10: Add to concerns: "Title may not directly match"

   - industry >= 15: "Industry aligns with your preferences"
   - location >= 10: "Location ({location}) is preferred"
   - salary >= 10: "Salary meets your threshold"
   - salary == 0 && !salary: Add concern: "Salary not disclosed"
   - skills >= 5: "Multiple skill matches found"

   - If usingDefaults: Add concern: "Using default criteria - populate profile for personalized scoring"

3. **generateSummary(score, reasons, concerns)**
   - score >= 90: "Excellent match ({score}/100). {reasons[0]}"
   - score >= 80: "Strong match ({score}/100). {reasons[0]}"
   - score >= 70: "Good potential ({score}/100). Worth reviewing: {reasons[0]}"
   - score < 70: "Moderate fit ({score}/100). Consider: {reasons[0] || 'May be stretch role'}"

Create tests in reasoning-generator.test.js:
- High score with all positive signals
- Medium score with mixed signals
- Low score with concerns
- Edge cases (empty job data, no reasons)
  </action>

```javascript
  job: { title, company, location, salary, fitScore, fitBreakdown, url },
  research: { httpStatus, warnings, researchedAt },
  reasoning: { score, summary, whyIncluded, considerations },
  notes,
  nextStep: 'Call confirm_job_to_dashboard or defer_job to proceed'
}
```

```javascript
// DISC-04: Present shortlist for review

// Include summary stats

// Returns:

  count: number,
  jobs: [{ id, title, company, fitScore, daysPending, hasResearch }],
  summary: { total, highFit, needsResearch, oldestDays }
```
