- Map skills to skills section format
- Return structure matching existing resume generator expectations:
```javascript
{

  summary: selectedSummaryBlock.content,
  experience: transformedExperience,
  skills: transformedSkills,
  education: profile.education || [],
  target_company: jobContext.company,
  target_title: jobContext.title
}
```

**selectRelevantExperience(profile, jobContext):**
- Score each project by keyword match with jobContext
- Return top N roles with their most relevant projects
- Preserve chronological order
