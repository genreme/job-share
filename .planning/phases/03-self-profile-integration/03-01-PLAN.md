**duplicate-detector.js:**
- Export detectDuplicates(profile, options = {})
- Use string-similarity with DEFAULT_THRESHOLD = 0.85 (85%)
- Options: { threshold, excludeCategories }
- Compare skills by name (case-insensitive)
- Compare stories by title + situation (weighted)
- Compare summaryBlocks by content (first 100 chars)
- Return array of CleanupFinding objects with:
  - type: 'duplicate'
  - ids: [item1.id, item2.id]
  - similarity: percentage (0-100)
  - reason: "'{name1}' and '{name2}' are {X}% similar"
  - suggestion: contextual (merge, remove, or keep if valid variants)

**staleness-detector.js:**
- Export detectStaleItems(profile, documentHistory = [])
- STALENESS_THRESHOLDS: AGE_DAYS = 180, USAGE_DAYS = 90 (per RESEARCH.md)
- Item is stale ONLY when BOTH conditions met (per CONTEXT.md):
  - updatedAt older than AGE_DAYS
  - Not used in documents within USAGE_DAYS (or never used)
- Check skills, stories, summaryBlocks, experience
- Return array of CleanupFinding objects with:
  - type: 'stale'
  - ids: [item.id]
  - reason: "Not updated in X days and not used in documents for Y days"
  - suggestion: "Review and update or remove if no longer relevant"

**gap-detector.js:**
- Export detectGaps(profile, jobContext = null)
- Detect two types of gaps:

Required field gaps:
- No communication preferences set
- No target roles defined
- Empty experience array
- Empty skills array

Thin evidence gaps (per CONTEXT.md "skills/achievements without supporting stories/metrics"):
- Skills with evidence.length < 2
- Experience projects without metrics
- Stories without projectRef

Contextual gaps (when jobContext provided):
- Leadership role but no leadership stories
- Technical role but few technical skills

Each gap includes:
- type: 'gap'
- field: path to missing/thin field
- severity: 'required' | 'thin-evidence' | 'contextual'
- reason: WHY this matters (per PROF-08b)
- suggestion: HOW to address it (per PROF-08b)
- relevantTo: job title if contextual

Write comprehensive tests for each detector:
- duplicates: test threshold edge cases, different entity types
- staleness: test BOTH conditions required, different item types
- gaps: test required fields, thin evidence, contextual gaps
