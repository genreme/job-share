   - Call updateCompanyResearch(jobId, findings)
   - Return success/error result

3. **startManagerResearch({ jobId, managerName }):**
   - Load job from dashboard
   - Use provided managerName or fall back to job.hiringManager
   - If no name available, return error with suggestion to set hiring manager first
   - Return researchHiringManager(jobId, name, company) template

4. **saveManagerResearch({ jobId, findings }):**
   - Call updateManagerResearch(jobId, findings)
   - Return success/error result

5. **getResearch({ jobId, type = 'highlights' }):**
   - If type='highlights', return getResearchHighlights(jobId)
   - Otherwise return getJobResearch(jobId, type) for full research

  <files>mcp-server/src/tools/generation.js, mcp-server/src/tools/review.js, mcp-server/src/services/email-generator.js, mcp-server/src/tools/generation.test.js, mcp-server/src/tools/review.test.js</files>
  <action>
**email-generator.js service:**

1. **generateEmailVariations({ jobId, emailType, context, toneCount = 3 }):**
   - Load job and profile
   - Load research (getJobResearch)
   - Define tones: ['professional', 'warm', 'direct'].slice(0, toneCount)
   - For each tone, create template with:
     - tone, emailType, context (job info, research highlights, profile name)
     - instruction based on emailType ('followup', 'thank_you', 'inquiry', 'response')
   - Return { status: 'variations_ready', jobId, company, emailType, variations, note: 'Review variations...', nextStep: 'User selects...' }

**generation.js tools:**

1. **generateOptimizedResume({ jobId, includeResearchReferences = false }):**
   - Load job, profile, research
   - Build resume using buildResumeFromProfile
   - Optimize using optimizeResumeForJob
   - Return { status: 'optimized', jobId, company, title, optimization: {...}, researchUsed, resumeData, nextStep: 'Call review_document...' }

2. **generateResearchedCoverLetter({ jobId, includeCompanyReferences = true, toneVariation = null }):**
   - Load job, profile, research
   - Use profile communication prefs for tone (or override)
   - Build cover letter structure (opener, body, closing as templates for Claude to fill)
   - Return { status: 'generated', jobId, company, title, coverLetter, researchUsed, toneApplied, nextStep: 'Call review_document...' }

3. **generateEmailResponse({ jobId, emailType, context, toneCount = 3 }):**
   - Delegate to email-generator service
   - Return variations

**review.js tools:**

1. **reviewGeneratedDocument({ documentType, content, jobId }):**
   - Load profile and job description (from job.notes)
   - Call reviewDocument(documentType, content, jobDescription, profile)
   - Format issues for user review (per CONTEXT.md: "flag + suggest")
   - Return { reviewId, documentType, scores, length, issues, totalIssues, readyToUse, blockers, nextStep }

2. **approveDocument({ documentType, jobId, documentPath = null }):**
   - Add approval to job.updates: { date, type: 'Document Approved', notes: '...' }
   - Save job data
   - Return { success, jobId, documentType, approvedAt, status: 'ready_to_use' }
   - Per CONTEXT.md: "Explicit approval required before document is marked 'ready to use'"
  </action>

**Case handlers (add to switch statement):**

```javascript
// Application Generation (Phase 7)
// Research
case 'start_company_research':
  result = startCompanyResearch({ jobId: args.jobId });
  break;
case 'save_company_research':
  result = saveCompanyResearch({ jobId: args.jobId, findings: args.findings });
  break;
case 'start_manager_research':
  result = startManagerResearch({ jobId: args.jobId, managerName: args?.managerName });
  break;
case 'save_manager_research':
  result = saveManagerResearch({ jobId: args.jobId, findings: args.findings });
  break;
case 'get_research':
  result = getResearch({ jobId: args.jobId, type: args?.type || 'highlights' });
  break;

// Document Generation
case 'generate_optimized_resume':
  result = generateOptimizedResume({
    jobId: args.jobId,
    includeResearchReferences: args?.includeResearchReferences
  });
  break;
case 'generate_researched_cover_letter':
  result = generateResearchedCoverLetter({
    jobId: args.jobId,
    includeCompanyReferences: args?.includeCompanyReferences,
    toneVariation: args?.toneVariation
  });
  break;
case 'generate_email_response':
  result = generateEmailResponse({
    jobId: args.jobId,
    emailType: args.emailType,
    context: args?.context,
    toneCount: args?.toneCount
  });
  break;

// Document Review
case 'review_generated_document':
  result = await reviewGeneratedDocument({
    documentType: args.documentType,
    content: args.content,
    jobId: args?.jobId
  });
  break;
case 'approve_document':
  result = approveDocument({
    documentType: args.documentType,
    jobId: args.jobId,
    documentPath: args?.documentPath
  });
  break;
```
