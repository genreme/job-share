<task type="auto">
  <name>Task 1: Create Research Schemas</name>
  <files>schemas/research.schema.js</files>
  <action>
Create Zod schemas for company and hiring manager research following patterns from RESEARCH.md:

1. **CompanyResearchSchema:**
   - id (uuid), jobId (number), companyName (string), researchedAt (ISO string), refreshedAt (optional)
   - firmographics object: size, industry, founded, headquarters, website (all optional strings)
   - funding object: stage, totalRaised, lastRound (optional strings), investors (string array), signals (string array)
   - culture object: values (string array), glassdoorThemes (string array), leadershipQuotes (array of {quote, speaker, source?}), workStyle (optional string)
   - news (array of {headline, date?, source?, relevance: 'high'|'medium'|'low'})
   - challenges (string array), competitors (string array)
   - products (array of {name, description?})
   - confidence ('high'|'medium'|'low'), sources (string array), highlights (string array)

2. **HiringManagerResearchSchema:**
   - id (uuid), jobId (number), managerName (string), researchedAt (ISO string)
   - background object: currentRole, company, yearsInRole (number?), previousRoles (string array), education (optional strings)
   - interviewStyle object: signals (string array), communicationPattern (optional), commonQuestions (string array)
   - linkedIn object: url (optional), activity (string array), connections (number?)
   - sharedInterests (string array), mutualConnections (string array), talkingPoints (string array)
   - confidence ('high'|'medium'|'low'), sources (string array)

Use .default([]) for arrays, .optional() for optional fields. Export both schemas.
  </action>

Run: `node -e "import('./schemas/research.schema.js').then(m => console.log(Object.keys(m)))"`
Should output: [ 'CompanyResearchSchema', 'HiringManagerResearchSchema' ]
  </verify>

<task type="auto">
  <name>Task 2: Create Company Research Service</name>
  <files>mcp-server/src/services/company-research.js, mcp-server/src/services/company-research.test.js</files>
  <action>
Create company research service with three functions:

1. **researchCompany(jobId, companyName):**
   - Returns template structure with empty/default fields for Claude to populate
   - Returns { status: 'template_ready', research: {...}, instructions: '...' }
   - Instructions list what to research: firmographics, funding, culture, news, challenges, competitors, products

2. **updateCompanyResearch(jobId, findings):**
   - Validate findings against CompanyResearchSchema
   - Save JSON to `data/job-research/${jobId}-company.json` using atomic write pattern (write temp, rename)
   - Generate and save markdown to `data/job-research/${jobId}-company.md` using generateCompanyMarkdown helper
   - Return { success: true, saved: { json: path, markdown: path }, highlights: [...] }
   - On validation error, return { error: '...', details: [...] }

3. **checkForExistingCompanyResearch(companyName):**
   - Scan data/job-research/*-company.json files
   - If same companyName (case-insensitive) found, return:
     { found: true, existingJobId, companyName, researchedAt, daysSinceResearch, highlights, suggestion }
   - suggestion: "Recent research available. Reuse?" if <30 days, "Older research available. Refresh recommended." otherwise
   - If not found, return { found: false }

4. **generateCompanyMarkdown(research):** (helper, not exported)
   - Generate human-readable markdown following RESEARCH.md template format
   - Include all sections: highlights, firmographics, funding, culture, news, challenges, competitors, sources

Import: uuid for IDs, fs for file ops, path for paths, CompanyResearchSchema from schemas
Use atomic write pattern: writeFileSync to temp path, renameSync to final path
  </action>

Tests should pass for: template generation, validation, save/load cycle, existing research detection
  </verify>
