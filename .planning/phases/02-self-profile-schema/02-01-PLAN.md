**Core metadata schema:**
```javascript
const ProfileMetadataSchema = z.object({
  version: z.number().int().positive(),
  createdAt: z.string(),  // ISO timestamp
  updatedAt: z.string(),  // ISO timestamp
  schemaVersion: z.literal('1.0'),  // For future migrations
})
```

**History entry schema (from RESEARCH.md Pattern 5):**
```javascript
const HistoryEntrySchema = z.object({
  id: z.string().uuid(),
  timestamp: z.string(),  // ISO timestamp
  action: z.enum(['create', 'update', 'delete']),
  entityType: z.enum(['experience', 'skill', 'summary', 'story', 'preference']),
  entityId: z.string(),
  previousValue: z.unknown().nullable(),
  newValue: z.unknown().nullable(),
  reason: z.string().optional(),
})
```

**Base profile structure (placeholder arrays for Plan 02-02 and 02-03):**
```javascript
const ProfileSchema = z.object({
  metadata: ProfileMetadataSchema,
  experience: z.array(z.unknown()).default([]),     // Populated in 02-02
  skills: z.array(z.unknown()).default([]),         // Populated in 02-02
  summaryBlocks: z.array(z.unknown()).default([]),  // Populated in 02-03
  stories: z.array(z.unknown()).default([]),        // Populated in 02-03
  preferences: z.object({
    targetRoles: z.array(z.unknown()).default([]),  // Populated in 02-03
    communication: z.unknown().optional(),           // Populated in 02-03
  }).default({}),
  history: z.array(HistoryEntrySchema).default([]),
})
```

**Implement createEmptyProfile():**
- Returns valid empty profile with metadata (version: 1, createdAt/updatedAt: now, schemaVersion: '1.0')
- Empty arrays for experience, skills, summaryBlocks, stories
- Empty preferences object with defaults
- Empty history array

**Implement loadProfile():**
- Check if PROFILE_PATH exists
- If not: create directory, call createEmptyProfile(), save it, return it
- If exists: read, parse, validate with validateProfile()
- Log warnings if validation fails (advisory mode)
- Return validated data

**Implement saveProfile(profile):**
- Validate with validateProfile()
- Log warnings if validation fails (advisory mode - warn but allow save)
- Atomic write: write to .tmp, then rename
- Return { success: boolean, warnings: Array }

**Implement addHistoryEntry(profile, action, entityType, entityId, previousValue, newValue, reason):**
- Creates history entry with uuid, ISO timestamp
- Appends to profile.history array (does NOT mutate - returns new profile)
- Returns { entry, profile } where profile is new object with updated history
