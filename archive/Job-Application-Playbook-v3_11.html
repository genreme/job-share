📖 Getting Started
Overview, setup checklist, and tips

What Is This?

This playbook is a structured system for applying to senior-level roles using AI as your strategic partner. Instead of generic applications, you'll build deeply researched, highly tailored materials that demonstrate real understanding of the company and role.

The playbook is organized into four groups: Foundation (do once), Application Process (per role), Interview Preparation, and Post-Interview. Prompts are designed to be copied directly into Claude (or another AI), with placeholders [LIKE THIS] that you fill in.

Why Claude

Optimized for Claude at claude.ai, which excels at strategic analysis and maintaining context across long conversations.

  • Opus 4.5 (Pro) — Most sophisticated outputs, best for nuanced writing
  • Sonnet 4.5 (Free/Pro) — Very capable, may need more iteration
  • Research Mode (Pro) — Significantly improves research phases

Prompts work with other AI tools (ChatGPT, Gemini, Copilot), though you may need to adjust for different capabilities and context handling.

Before You Start

  • Complete Foundation → Setup once
  • Start a new chat for each application
  • Paste your Application Profile at the start
  • Attach your baseline resume
  • Paste or attach the full job description
  • Have the company website URL ready

How to Use This Playbook

Time Investment

  • Foundation: 1–2 hours (complete once)
  • Application Process: 2–3 hours per role
  • Interview Prep: 1–2 hours per interview
  • Post-Interview: 30–60 min as needed

Context & Outputs

  • Claude retains everything in a chat—no need to re-paste
  • Reference outputs by ID: "Using 1A and 3A..."
  • Save Foundation outputs externally for reuse

Refining Outputs

When Claude's output needs adjustment, use targeted follow-ups:

  • Too generic: "Make this more specific to [COMPANY'S SITUATION]"
  • Wrong tone: "Adjust tone to be more [formal/conversational/confident]"
  • Missing emphasis: "Emphasize my experience with [SPECIFIC SKILL] more"
  • Too long: "Tighten this to [X words] while keeping the key points"
